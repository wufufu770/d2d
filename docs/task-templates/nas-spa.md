> 用法：任务书文件（--task-file）在通用结构（目标声明/授权范围/凭据/使命/纪律）之上，
> 追加本模板的"形态坑提示"节。指纹差异/前端路由 fallback 是 r2b 四轮（10150911/10151004/
> 10160333/场验两轮）反复消耗预算的同一族坑。

## 形态坑提示（追加到任务书）

### 1. SPA catch-all 路由
任意未知路径返回 200+同一前端壳（同一 status/content-type/近似字节）——"端点存在性"
判定必须用**响应体差异化**（特征子串/字节级对比），status code 无判别力。

### 2. 环境一致性判据（与 ECC 信号协同）
- 同路径秒级双探：指纹漂移=形态切换前兆（tarpit/蜜罐嫌疑——ECC homogeneous 信号对应面）。
- 异构路径同指纹：`/`、`/api/x`、`/static/x` 同 status+同 hash=同响应嫌疑。
- CSP/安全头暴露非目标 origin（如 img-src 指向内网其他主机）=lab/deployment 拓扑线索。

### 3. 认证面
- 登录端点路径不可假设（v1/v2 API 版本族、/api/auth/*、/admin/login* 均可能）——404/401
  语义分层记录；锁出形态响应（"失败次数过多"/429）即停该向，锁出窗内重试=预算浪费+证据污染。
- 凭据有效性=考题非前提：操作者凭据走 AUTH 原语单发验证，禁止 spray 兜底。

### 4. 预算护住率
tarpit/全路径同响应确认后：立即收束广度探测、转 evidence/handoff 落盘+方向声明
（intents.json）——在 tarpit 上继续消耗=零信息增量。
