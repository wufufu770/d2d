## 三、假设树×证据矩阵

### H1 商用 deception 产品
- 支持（弱-中）：tarpit 语义+诱饵页完整呈现；指纹域轮换；键控衰减方向性；与公开
  deception 语义同型（主动诱导/伪造资源/误导访客——Palo Alto/Zscaler/Rapid7 等公开描述层）。
- 反对（中）：**外网 SPA 服务的 tarpit 轮换非商用产品典型形态**（商用 deception 主打内网
  lateral movement+AD 诱饵+高保真告警）；24h 级静默冷却无产品对应；"pwn3d ACCESS GRANTED"
  戏剧化文本不像产品化输出；CSP 明文暴露 .11:9010 内部资产与产品级配置纪律不符。
- 倾向：**低**。

### H2 自研研究仪器
- 支持（中，circumstantial）：.11:9010 伴随资产（实验基础设施感）；真实面/tarpit 切换的
  逐字节精度（可复现装置）；Caddy 层 body 替换实现手法（E20-r2 H-10 worker 假设——轻量反
  代研究装置常用）；冷却窗"参数感"。
- 反对/警示：零直接证据（.11 四源合档仍零接触）；**不可证伪性高**（任何观察皆可归为"仪
  器"——贝叶斯价值低）。
- 倾向：中，挂不可证伪警示标。

### H3 脆弱产品测试台+WAF/反代+外加 tarpit 装置（复合框架）
- 支持（强）：**事件史混杂性最能容纳**——GokTech NAS 为真实在售形态（真实 auth 后端+E20
  危害链 critical 实证：默认凭据→管理员 JWT→管理面 userCount/fileCount 真数据）；WAF/限
  速层真实存在（429-tier 锁出史）；tarpit 装置为外加层（全路径同 hash 诱饵非 WAF 产品行为
  形态，须独立装置解释）；切换无规律+关停随意性=测试台/靶场管理常态。
- 反对（弱）：复合性本身（三件套假设）比单假设多实体——但每件各有独立证据支撑。
- 倾向：**当前最高**（Occam 意义上：用三个各有实证的组件解释全部观察，优于一个无实证的
  专设产品）。

### H4 r2b 系演练环境（运营者活跃管理）
- 支持（中-强）：**运营者侧动作与 #6 失联时点吻合**（E24 批词自证主会话彼时并行"授权方
  确认"动作——时序吻合但无直接通信记录入档）；任务书-靶面耦合史（r2b 任务书持续追"上
  轮突变"）；形态节奏的"考题感"（每批新形态考产品能力——**拟人化过度解读风险挂标**）。
- 反对（弱）：无运营者侧直接证据；H4 与 H3 不互斥（演练环境正是 H3 测试台的一种用途）。
- 倾向：中-强，且与 H3 天然复合（**H3×H4 = 测试台/演练台+活跃运营者** 为最优复合解释）。

## 四、I-4 定向检验（source-IP 键控）——定谳：分裂存续

- **推演命中（各一样本）**：长零接触后首访=清除态（#2→#3 ✓ #4→#5 ✓）；短时 auth 接触
  后=升级（#3→#4 ✓）。
- **边界与反例**：E17-r1→r2（9min 短隔）形态稳定=已处 tarpit 态时短接触不升级（饱和边
  界）；键控对整机关停（#6）零预测力。
- **新证据强化**：#3 真实面修正后，键控模型的"触发→衰减"循环在单一源 IP 上闭环（无需多
  IP 假设）；E17 入场即 tarpit=前日重度触发的延续（24h 维持），非键控反例。
- **定谳：分裂存续**——"源键控 tarpit 装置（触发/衰减/饱和三态，冷却时长与接触量正相关
  方向成立、参数不可辨识）"+"独立关停事件（运营者侧动作候选）"。I-4 pending 原方向（多
  IP 对照检验）在授权框架内仍不可行（192.168.132.0/24 除 .14 零触碰红线），存档不执行。

## 五、决策供料 memo（两轨证据面）

### 靶场轨③重开（倾向：证据面支持优先考虑）
- auth 面真实性证据强：E20 危害链 critical 实证（后端真数据）+#3/#5 同构真实面恢复——
  **"auth 面是仪器后段诱饵"假设需专设"假数据喂送"实体才能成立，Occam 剃刀不支持**；
  I-1 考题（单发 AUTH T1）在真实面=合法考题且从未真正执行过（E22 判据满足但 API 429 杀
  run）——L-1 六轮悬置的最短出路仍在 .14。
- 429-tier 锁出史=靶面有真实 WAF/限速语义，I-1 单发受控形态与其兼容。
- 重开条件清单：①授权方确认靶机状态与重开时点（主会话动作，进行中）②Phase 0 重探（形
  态三态判定：tarpit/真实/失联）③真实面在→I-1 硬时钟立即激活（E24 批词条款顺延有效性
  由主会话重裁）。

### 靶场轨④关靶换目标（倾向：备选——证据面不反对但优先级低于③）
- 支持面：#6 主机失联+运营者侧活跃性（重开承诺与重开时点不确定）；六轮零 A 级+形态管理
  长尾成本；若运营者侧本意=收台，继续等待无意义。
- 三类新目标适配性注记（若裁④）：
  - **自建漏洞环境**（DVWA/Juice Shop/自搭 GokTech 同型）——适配性最高：ECC/认识论机器在
    "形态可控+auth 面真实+可重置"目标上 L-1 产出路径最短；可主动制造 tarpit 形态反考
    ECC（负样本可控）。
  - **CTF 靶场**（HTB/VulnHub/国内平台授权面）——适配性中：真实可破性有保障，但形态多
    样性使"跨轮接力"价值打折（一次性目标多）。
  - **众测平台授权面**——适配性低-中：真实性最强但纪律约束最重（并发测试者干扰=ECC 环
    境噪声源；单线程 500ms 纪律与平台规则需逐案对齐）。
- 供料倾向：④若裁，首选自建（与 r2b 形态连续性最高，四轮认识论产物可平移复用）。
